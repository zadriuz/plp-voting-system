LESSON BREAK:
• java.sql.Connection - active line between MySQL and Java
• java.sql.DriverManager - the telephone operator that locates the DB using the given credentials
• javax.swing.JOptionPane - for popup messages
• java.sql.PreparedStatement - for query simplification and finalization. it's also for security to avoid SQL Injection; it forces to pre-compile SQL template before inserting raw data.
• java.sql.ResultSet - for receiving the table thrown by MySQL using executeQuery()
• java.sql.SQLException e - exception thrown by SQL in case of errors

• return - forces the program to instantly exit the current method it is running, it will end the method asap.
• BINARY - gets EXACT BYTE VALUES of text rather than letters to ENSURE CASE-SENSITIVITY
